## What is this?
This repo contains interactive visualisation(s) of
- Mixed-strategy best response curves and the steps to draw them
- ... (TBD)

which I made on Shiny.

## How do I use this?
1. Clone this project into RStudio/Positron
2. Open the project
3. Navigate to one of the sub-folders containing your visualisation of choice and open the R file inside
4. Run the app. Have fun!

## On which R/IDE combination have you tested these?
- R: 4.6.1
- IDE: **RStudio** Version 2026.10.0+233
